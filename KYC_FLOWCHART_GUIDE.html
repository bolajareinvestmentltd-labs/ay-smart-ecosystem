Visual Guide for Money-Safe Marketplace Operations

1️⃣ User Journey (Product Flow)

What users see and do

  • Sign up → Complete profile → Submit KYC documents
  • Wait for verification → Get approved by admin
  • Once verified: list properties, buy, manage wallet
  • Checkout triggers escrow hold (funds stay safe)
  • View transaction history with full audit trail

⚠️ Critical Rules

  • NO checkout or listing allowed without KYC verification
  • NO direct transfers - all money goes through escrow
  • Admin approval required for profile activation
  • Rejected KYC can be re-submitted

2️⃣ Admin Dashboard (Operations Flow)

What admins manage

  • Review and approve pending KYC applications
  • Manage escrow holds (release, refund, escalate)
  • View financial summary and reconciliation
  • Handle disputes and issues
  • Export audit logs and financial reports

⚠️ Admin Powers & Restrictions

  • Approve/reject KYC with reason logged
  • Release, refund, or escalate escrow (all logged)
  • View financial ledger and reconciliation
  • Contact users and resolve disputes
  • Export audit trail for compliance

3️⃣ Frontend Screens to Build

User Screens

📋 KYC Status

Show user's KYC state, progress, and rejection reasons (if any). Allow retry if rejected.

📝 KYC Form

Collect documents based on account type (NIN + selfie for sellers, matric for students, both for dual accounts).

Show loading state while documents are being verified. Display timestamp and estimated wait time.

Browse and list properties. Only visible to KYC-verified users. Shows filters and search.

📊 Transaction History

5️⃣ Quick Reference - Trust Chain

The Complete Money Flow

  • User: Register → Profile → Submit KYC docs
  • System: Verify against provider (Dojah)
  • Admin: Approve verified user
  • User: Now can list or buy (only when verified + approved)
  • Buyer: Clicks checkout
  • System: Debit buyer wallet → Create escrow → Hold funds
  • Seller: Accepts or cancels
  • Admin: Reviews if disputed
  • System: Release to seller OR refund buyer → Create audit log
  • Admin: View financial audit & reconciliation
